Station 01 · Understand

📚 Learn It!

Let's learn to add money carefully. Keep the place values aligned, calculate one column at a time, and check your answer.

How to add money

Use these four steps whenever you solve an addition question.

1. WriteArrange the amounts in columns.
2. AlignKeep the same place values together.
3. AddAdd from the smallest place value and regroup when needed.
4. CheckEstimate or use the inverse operation to check.
Worked example
RM1,250 + RM2,375 = RM3,625

Thousands: 1,000 + 2,000 = 3,000
Hundreds: 200 + 300 = 500
Tens: 50 + 70 = 120
Ones: 0 + 5 = 5
Total: RM3,625.

EXTRA HELP · STEP BY STEP

💗 Guided GeoGebra Mission: Let’s solve it together!

Keep the original mission above as your task. Use these steps if you need help completing it. Open GeoGebra using the pink button above, then type calculations without commas (for example, 1250 + 2375) and press Enter.

Step 1 · Open GeoGebra

Click Open GeoGebra Calculator above. In the new tab, find the input bar where you can type calculations.

Step 2 · Predict and calculate

Estimate RM1,250 + RM2,375 first. A reasonable estimate is about RM3,600. Then enter 1250 + 2375.

Answer: 3,625. So RM1,250 + RM2,375 = RM3,625.

Step 3 · Try different calculations
  • 1250 + 2375 = 3,625
  • 2000 + 3000 = 5,000
  • 4500 + 2500 = 7,000
  • 6250 + 3750 = 10,000

Notice that the total changes when either amount changes.

Step 4 · Change one amount

Start with 1250 + 2375 = 3,625. Change the first amount to 2250 + 2375 = 4,625.

Observation: The first amount increased by RM1,000, so the total also increased by RM1,000 while the second amount stayed the same.

Step 5 · Find two pairs that make RM10,000
  • 6250 + 3750 = 10,000
  • 4000 + 6000 = 10,000

Both pairs have different amounts but the same total.

Step 6 · Sample answers for your notes

Prediction: Approximately RM3,600.

Calculation: RM1,250 + RM2,375 = RM3,625.

Changing one amount: When RM1,250 becomes RM2,250, the total increases from RM3,625 to RM4,625.

Two pairs totalling RM10,000: RM6,250 + RM3,750 = RM10,000 and RM4,000 + RM6,000 = RM10,000.

Pattern: If one amount increases by RM1,000 and the other stays the same, the total also increases by RM1,000. Different pairs can make the same total.

💡 Quick Practice

A pupil buys two items costing RM3.20 and RM2.50.

RM3.20 + RM2.50 = RM5.70

If the pupil pays RM10.00:

RM10.00 − RM5.70 = RM4.30

So, the change is RM4.30.
